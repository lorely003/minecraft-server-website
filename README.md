# minecraft-server-website
Implementation of HTML, CSS, and JavaScript to create a responsive and interactive website that contains information about a minecraft server so friends can join, explore activities, and create a community.

## Live Demo

View the website here:

https://lorely003.github.io/minecraft-server-website/

## About the Project

This project was created using HTML, CSS, and JavaScript. The goal was to build an organized and visually engaging website where users can view information about a Minecraft server and interact with website features.

The project also allowed me to practice front-end development concepts such as page structure, styling, navigation, JavaScript event handling, and accessibility features.

## Technologies used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Features

- Navigation bar with links to different sections
- Minecraft server information
- How to join a Minecraft server embedded video
- Upcoming activities section
- Sign-up section
- Dark mode toggle
- Reduced motion accessibility option
- Interactive buttons and JavaScript functionality
- Responsive webpage layout
